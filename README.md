# VoiceDrama Studio

**台詞の音声化、音声ドラマの編集、ゲーム用の画像・アニメーション素材づくりを、ブラウザから行う制作ツールです。**

自分のパソコンでアプリを起動し、ブラウザに表示される画面で操作します。台本からAI音声を作るほか、録音済みの声や手持ちの画像・効果音を取り込んで作品にまとめることもできます。

## 何ができる？

上部のメニューから、目的に合う画面を選びます。

| やりたいこと | 使う画面 | できること・用途 |
|---|---|---|
| 会話劇・朗読・ナレーションを音声作品にしたい | **ボイスドラマ** | 台本の作成、登場人物ごとの音声生成、録音音声の取り込み、BGM・効果音との編集。完成音声をWAV／MP3で保存 |
| ノベルゲームの台詞に声を付けたい | **ゲーム音声** | TyranoScriptの `.ks` を取り込み、台詞ごとの音声とボイスIDを管理。音声・シナリオのコピー・対応表をZIPで出力 |
| キャラクター・背景・アイテムの画像が欲しい | **画像・映像** → ドット絵生成 | PixelLab／OpenAIの画像APIで生成・編集。参考画像からの描き直しやドット絵化にも対応 |
| 歩行・攻撃モーションや魔法の演出を作りたい | **画像・映像** → ドット絵生成／戦闘シーケンス | PixelLabでアニメーション素材を生成し、画像・動き・効果音を時間順に配置。GIF／音声付きMP4などで出力 |
| ゲームの会話枠・メニュー枠が欲しい | **画像・映像** → UI枠ビルダー | AIで枠画像を生成。または手持ちの枠画像の四隅を保って伸縮し、PNGで保存 |
| 画像をAsepriteで編集できる形にしたい | **Aseprite** | PNG／GIF／WebPの取り込み、レイヤー・フレーム付きスプライトの作成、PNG／GIF／スプライトシートへの出力 |

**最初からすべてを導入する必要はありません。** 録音済み音声の編集には音声合成AIが不要で、手持ちの画像を使ったシーケンス編集には画像生成APIが不要です。

### パソコン内で行う処理と、外部サービスを使う処理

- **パソコン内で処理**：台本・素材の管理、音声の編集、Irodori-TTS／Qwen3-TTSによる音声合成、シーケンスの編集・書き出し、Aseprite連携。
- **インターネット接続が必要**：初回のライブラリ・AIモデルのダウンロード、PixelLab／OpenAI APIによる画像生成。API生成では指示文や参照画像を選択したサービスへ送信します。
- **画像APIには別途利用料金がかかる場合があります**。ツール内のデモモードは、API送信・課金なしでサンプルを表示します。デモは実際のAI生成ではありません。

## 起動するまで

### 1. 必要なものを用意する

このガイドは **Windows 10／11** 向けです。

| 必要になる場面 | 用意するもの |
|---|---|
| アプリ本体の起動 | **Python 3.10以降**、Chrome／Edgeなどのブラウザ、初回セットアップ用のインターネット接続 |
| Irodori-TTSで音声を生成 | **NVIDIA製のCUDA対応GPU**、Irodori-TTSとその実行環境。モデル保存用の空き容量も必要 |
| Qwen3-TTSで音声を生成 | Qwen3-TTSを実行できる別のPython環境 |
| MP3の書き出し・幅広い音声形式の読み込み | **FFmpeg** |
| PixelLab／OpenAI APIで画像を生成 | 利用するサービスのアカウント、APIキー、利用枠・請求設定 |
| Aseprite連携 | インストール済みの**Aseprite本体** |
| AIに演技指示や画像生成用の文章を提案させる | **Ollamaと対応モデル**（任意） |

GPUはアプリの画面表示や素材整理のための必須条件ではありません。このツールのIrodori-TTS連携はCUDAで実行するため、Irodori-TTSでの音声生成に必要です。必要なGPUメモリは選ぶモデルによって異なります。

### 2. 本体をダウンロードして展開する

1. [このリポジトリ](https://github.com/mikan111617/VoiceDramaStudio)の **「Code」→「Download ZIP」** を選びます。
2. ダウンロードしたZIPを右クリックし、**「すべて展開」**します。
3. 展開したフォルダを開き、`app.py` と `start_windows.bat` があることを確認します。

ZIPの中から直接起動せず、フォルダ全体を展開してください。保存先は、たとえば `C:\VoiceDramaStudio` のような場所にします。

### 3. Pythonを入れて起動する

1. [Python公式サイト](https://www.python.org/downloads/)からPython 3.10以降をインストールします。インストーラに **「Add python.exe to PATH」** がある場合はチェックを入れます。
2. 展開したフォルダの **`start_windows.bat`** をダブルクリックします。
3. 初回は必要なライブラリを自動でインストールします。完了するまで待ちます。
4. ブラウザが開いたら起動完了です。自動で開かない場合は、アドレス欄に **`http://127.0.0.1:8765`** を入力します。

このアドレスは、自分のパソコンで動いているアプリの画面です。使っている間は、起動時に開いた黒いウィンドウを閉じないでください。

**2回目からも `start_windows.bat` で起動します。** 終了するときは生成・書き出しが終わり、画面の保存表示を確認してから、黒いウィンドウで `Ctrl+C` を押します。ブラウザを閉じるだけではサーバーは終了しません。

### 4. MP3などを使う場合はFFmpegを入れる

Windowsのコマンドプロンプトで、次を実行できます。

```bat
winget install --id Gyan.FFmpeg
```

インストール後は起動用ウィンドウを開き直し、アプリを再起動してください。コマンドプロンプトで `ffmpeg -version` を実行して情報が表示されれば、認識されています。WAVの編集・書き出しから試す場合は、後から導入しても構いません。

## AIで音声を作るための準備

**手持ちの音声を編集するだけなら、この章は飛ばせます。**

TTSは「文章を音声にする仕組み」です。本体には音声合成モデルを同梱していないため、Irodori-TTSまたはQwen3-TTSを別途用意します。

### Irodori-TTSを使う

1. [Git](https://git-scm.com/)と[uv](https://docs.astral.sh/uv/getting-started/installation/)をインストールします。
2. コマンドプロンプトを開き、次を1行ずつ実行します。以下は `C:\Irodori-TTS` に導入する例です。

   ```bat
   cd /d C:\
   git clone https://github.com/Aratako/Irodori-TTS.git
   cd Irodori-TTS
   uv sync --extra cu128
   ```

3. VoiceDrama Studioの **「TTS環境の設定」** を開きます。
4. **「Irodori-TTSのフォルダ」** に `C:\Irodori-TTS` を指定します。`infer.py` が入っているフォルダを選んでください。
5. **「Irodori用Python実行ファイル」** は、上の手順なら空欄で構いません。`.venv\Scripts\python.exe` が自動で使われます。
6. **「設定を保存」** を押します。

キャラクターのモデルは、まず画面で選べる **「Irodori v4.1 Small」** から試せます。初回生成時にはモデルをダウンロードするため時間がかかります。導入要件やCUDA環境の詳細は[Irodori-TTS公式ガイド](https://github.com/Aratako/Irodori-TTS)を確認してください。

### Qwen3-TTSを使う場合

[Qwen3-TTS公式ガイド](https://github.com/QwenLM/Qwen3-TTS)に沿って、本体とは別のPython環境を用意します。**「TTS環境の設定」→「Qwen3-TTS用Python実行ファイル」** に、その環境の `python.exe` を指定してください。

- **Base**：参照音声（声のお手本）を使います。
- **VoiceDesign**：文章で声の特徴を指定して声を作ります。

### Ollamaは補助機能

[Ollama](https://ollama.com/)は、演技指示の案や画像生成用の文章を考えさせたい場合に使います。音声・画像の制作に必須ではありません。画像の特徴を分析させる場合は、画像入力に対応したモデルが必要です。

## ボイスドラマを作る

**台本を用意 → 声を割り当てる → 音声を作る・取り込む → BGMと調整 → 書き出す**、という流れです。最初は登場人物1人・台詞2行ほどで試すと、操作を確認しやすくなります。

### 1. 作品と台本を作る

上部の **「ボイスドラマ」** を開き、作品名を押します。「新規プロジェクト」にタイトルを入力して **「この名前で新規作成」** を選びます。

**「01 台本・台詞」→「＋ セリフを追加」** で、話者と台詞を入力します。

| 話者 | 台詞 | 演技指示の例 |
|---|---|---|
| 案内役 | ようこそ。こちらへどうぞ。 | 穏やかに、ゆっくり案内する |
| 来客 | ありがとうございます。 | 少し緊張しながら答える |

「シーン」は場面ごとのまとまりです。場所や時間が変わるところで、左側の **「＋ シーンを追加」** を使って分けられます。

### 2. キャラクターの声を決める

1. **「02 キャスト・声」→「＋ 共通キャラクターを追加」** を選びます。
2. 台本の話者と同じ名前にして、使用する音声エンジン・モデルを選びます。
3. 声のお手本があれば **「＋ 参照音声ファイルを登録」** で取り込みます。BGMや他の人の声が入っていない音声を使います。
4. お手本がなければ「声の説明」を入力し、**「Voice Designで声を作成」** を試します。試聴して **「この声を使う」** で選べます。
5. **「キャラクター設定を保存」** を押します。「この作品の話者と声」で、話者への割り当てを確認します。

共通キャラクターは、複数のボイスドラマ作品とゲーム音声で使えます。名前・別名による自動の対応付けのほか、話者ごとに使う声を指定できます。設定を変えると、その声を使う他の作品にも影響します。

### 3. 台詞の音声を作る、または取り込む

**AIで作る場合**は、台詞を選んで右下の **「この台詞を生成」** を押します。試聴して、必要なら台詞や演技指示を直して作り直します。

- まとめて生成する場合は **「このシーンの未生成を生成」**、**「複数シーンをまとめて生成」**、**「キャラクターを選んで生成」** を使います。
- 作り直した音声は「テイク」として残り、**「使うテイク」** で採用する音声を選べます。
- **「要再生成」** は、台詞・声・読み方などの設定が変わり、保存済み音声にまだ反映されていない状態です。
- **「04 読み方」** では固有名詞の読みを辞書登録できます。台本の表記は保ち、音声生成時の読みだけを変更します。辞書はゲーム音声と共通です。

**録音済み音声を使う場合**は、**「手持ちの音声ファイルを台詞に割り当て」** で取り込みます。複数ファイルをまとめて選び、割り当て先を確認して登録できます。AI生成した音声と混ぜて使うこともできます。

### 4. BGM・効果音と合わせる

**「03 音声ライブラリ」** にBGM・効果音・環境音を追加し、「BGMトラックへ配置」などを選びます。

右上の「マルチトラック」は、複数の音を時間に沿って並べる場所です。並んだ音声のひとつひとつを「クリップ」と呼びます。

| 操作 | 調整できること |
|---|---|
| クリップを左右にドラッグ | 音を鳴らし始める位置 |
| クリップの右端をドラッグ | 再生する長さ |
| クリップを選んで右下を編集 | 音量、フェード、ループ、トリミングなど |
| 「台詞クリップを台本順に並べる」 | 台本の順番と台詞間の「間」に合わせた配置 |
| 再生ボタン | 台詞とBGM・効果音を合わせた試聴 |

複数の作品で使うBGMなどは「共通ライブラリ」へ登録すると再利用できます。

### 5. 完成音声を書き出す

上部の **「完成音声（WAV/MP3）を書き出す」** を押します。

- 表示中のシーンだけ、または複数シーンをつないだ音声を出力できます。
- 複数シーンの場合は、順番と場面間の無音を指定し、切り替わりを試聴できます。
- MP3には作品タイトル・制作名義・ジャケット画像を埋め込めます。
- 完成音声は本体フォルダの **`exports/`** に保存されます。
- 台詞を個別ファイルで使う場合は **「このシーンの台詞音声をZIPで保存」** を使います。

### 台詞が多い場合はExcelでまとめて編集

**「一括取り込み用Excelひな形」** をダウンロードし、2行目から記入して **「Excelの台本を取り込む」** で読み込みます。

| 台詞ID | シーン | 話者 | 台詞 | キャプション | 間(秒) | 音声ファイル名 |
|---|---|---|---|---|---|---|
| 初回は空欄 | 入口 | 案内役 | ようこそ。 | 穏やかに | 0.6 | guide_001.wav |

キャプションは演技指示、間は次の台詞までの無音です。取り込みは「追加・更新」と「シナリオをすべて置き換える」を選べます。

**編集し直す場合は、アプリから「台本をExcelで書き出す」で保存したファイルを使ってください。** 台詞IDを残すことで、既存の台詞に対する変更として取り込めます。

## ゲームの台詞に声を付ける

**TyranoScript（`.ks`）で作ったノベルゲームの台詞音声をまとめて用意するための画面です。** ボイスドラマとは別のプロジェクトとして管理され、取り込み元のKSファイルは書き換えません。

1. 上部の **「ゲーム音声」** へ移動し、新しいプロジェクトを作ります。
2. **「04 ファイルの取り込み」→「① KSを読み込む」** でシナリオを追加します。複数回に分けて追加できます。既存のボイスID履歴を使う場合は、KSより先に履歴を読み込みます。
3. すべてのKSを読み込んだら **「② 全KSのボイスIDを一括確定」** を押します。各台詞に `v00001` のような識別番号が付きます。
4. **「02 キャスト・声」** で、話者ごとに共通キャラクター、またはゲーム音声専用の声設定を割り当てます。
5. **「03 読み方・アクセント」** で読み方を調整し、必要に応じて台詞ごとの演技指示を入力します。
6. **「01 台本・台詞」** で対象を選び、**「選択した台詞を生成」** を押します。シナリオ・話者・未生成の台詞などで対象を絞れます。
7. 試聴して、必要な台詞だけ修正・再生成します。「読み上げテキスト」は元のKSとは別に調整できます。
8. **「ゲーム用に書き出す（ZIP）」** で保存します。

キャラクターシートJSONを取り込むと、音声化する人物を絞れます。ボイスリストJSONからの取り込みや、キャプションCSVの書き出し・取り込みにも対応しています。演技指示をまとめて考えたい場合は、画面の「キャプション作成用のAI依頼文をコピー」とCSVを組み合わせて使えます。

### ZIPに入るもの

| 内容 | 用途 |
|---|---|
| `audio/` | 生成済みの台詞音声（WAV／MP3） |
| `voiced_scenarios/` | ボイスIDを付けたKSのコピー |
| `voice_map.json`、`voice_maps/` | ボイスIDと音声ファイルの対応表 |
| `voice_id_registry.json` | 次回の作業に引き継ぐボイスID履歴 |
| `missing_voices.json` | 未生成・要再生成など、出力対象の音声が揃っていないID |

書き出した素材は、ゲーム側の音声再生方式に合わせて組み込んでください。**ZIPを書き出すだけで、ゲーム本体への配置や再生設定まで完了するわけではありません。**

## 画像・ドット絵を作る

上部の **「画像・映像」** を開きます。キャラクター、アイテム、背景、UI、エフェクトなどを作り、生成履歴とアセット管理に保存できます。「アセット」は、制作に使う画像や音声などの素材のことです。

### 最初の1枚を作る

1. **「① 何を作りますか？」** で素材の種類を選びます。
2. **「② どうやって作りますか？」** で制作方法を選びます。
3. 説明文、必要な参照画像、サイズなどを入力します。
4. まずは **「デモモード」** をオンにして、生成からプレビュー・保存までの流れを確認できます。
5. 実際に生成する場合は「接続・料金を表示」を開き、PixelLabまたはOpenAIのAPIキーを登録します。
6. 詳細設定でサービス・モデルを確認し、デモモードをオフにします。費用の確認画面を読んでから生成します。
7. 結果をプレビューで確認し、保存します。生成履歴から設定の再利用や再生成もできます。

### 制作方法の選び方

| 方法 | 入力するもの | 向いている用途 |
|---|---|---|
| **新しく描く** | 作りたい画像の説明 | 新しいキャラクター、背景、小物など |
| **参考に描き直す** | 参考画像と説明 | 元画像の特徴を参考に、ポーズ・頭身・構図を変えて描く |
| **そのままドット絵化** | 元画像 | 元の構図や形をなるべく保ってドット絵にする |
| **動かす** | 元になるドット絵と動きの説明 | 待機、歩行、攻撃などのアニメーション素材 |
| **動くエフェクト** | 炎・落雷・斬撃などの説明、必要なら参照画像 | 魔法や攻撃の視覚効果 |

利用できる方法は、素材の種類とサービスによって変わります。「参考に描き直す」はPixelLab Proを使う手順で、「動かす」「動くエフェクト」はPixelLab向けです。元画像の細部が完全に保たれるとは限らないため、生成後に確認してください。

### サービスの違い

- **PixelLab API**：ドット絵、画像のドット絵化、キャラクターアニメーション、動くエフェクトの制作に使います。
- **GPT画像生成（OpenAI API）**：静止画像の生成・編集に使います。ドット絵として使う場合は、仕上がりやピクセルサイズを確認してください。
- **ChatGPT Plus（画像を貼り付け）**：画面で指示をコピーし、ChatGPT側で画像を作ってから、このツールへ貼り付け・ドロップで取り込みます。ツールからChatGPTの画像生成を自動実行する機能ではありません。

APIキーは[PixelLabのアカウント画面](https://www.pixellab.ai/account)または[OpenAI Platform](https://platform.openai.com/api-keys)で用意します。**ChatGPTの契約とOpenAI APIの利用料金は別です。** ツールの予算表示は利用管理の目安であり、請求額の厳密な上限ではありません。実際の残高・料金は各サービスで確認してください。

### 会話枠・メニュー枠を作る

左メニューの **「UI枠ビルダー」** では、2つの作り方を選べます。

- **AIでゼロから作る**：枠の用途・デザイン・サイズを指定してPixelLabで生成します。実生成にはAPI接続が必要です。
- **既存画像から伸縮する枠を作る**：手持ちの画像やサンプルの四隅を固定し、辺と中央を繰り返して希望サイズの枠にします。この「9-slice」処理はパソコン内で行います。

できた枠は透過PNGで保存できます。文字・数値の表示やボタンを押したときの動作は、ゲーム側で設定します。

<a id="animation"></a>

## アニメーション・戦闘演出を組み立てる

**用意した画像・アニメーション・効果音を組み合わせて、短い演出を作る機能です。** たとえば「走って近づく → 攻撃 → 魔法と効果音 → 元の位置へ戻る」を組み立てられます。

1. **「画像・映像」→「アセット管理」** で、キャラクター・背景・エフェクト・音声を取り込みます。GIFや、複数コマを1枚に並べたスプライトシートも使えます。
2. **「戦闘シーケンス」** で新規作成し、画面サイズとFPS（1秒あたりのコマ数）を決めます。
3. 素材を選び、キャラクター・背景・エフェクト・効果音などのレーンへ追加します。
4. 開始フレーム、長さ、表示位置、必要なら移動先・左右反転・音量を調整します。位置はプレビュー上で指定できます。
5. 再生して、動きと効果音のタイミングを合わせます。
6. 目的に合う形式で書き出します。

「接近 → 攻撃 → 帰還」をまとめて配置する機能もあります。**走る・攻撃するアニメーション素材そのものは、別途生成するか取り込んで用意します。**

### カメラ・カットイン・演出効果（ロボットアニメ風の演出）

レーンに **カメラ**・**カットイン**・**演出効果** があります。カメラと演出効果は素材なしで追加できます。

| レーン | 設定 | 内容 |
|---|---|---|
| カメラ | 開始ズーム／終了ズーム、開始X・Y→終了X・Y、画面揺れ | 寄り・引き、カメラの移動、画面揺れ。開始X・Yは映す中心（画面中央からのずれ） |
| カットイン | 顔画像（「追加するアセット」で選択、任意）、台詞、顔の位置、文字送り、色 | 画面下に顔と台詞のパネルを表示 |
| 演出効果：集中線 | 中心（開始X・Y）、強さ、色、重ね順 | 中心へ向かう線 |
| 演出効果：スピード線 | 強さ、色、重ね順、左右反転（流れる向き） | 横に流れる線 |
| 演出効果：画面フラッシュ | 強さ、色 | 画面全体が光り、クリップの長さで消える |
| 演出効果：ビーム | 発射位置（開始X・Y）、着弾位置（終了X・Y）、太さ、色 | 伸びる→保持→細くなる |
| 演出効果：ヒットストップ | 長さ | その間、キャラ・背景・エフェクトが止まる。カメラの揺れ・カットイン・効果音は止まらない |

背景レーンには **横スクロール／縦スクロール**（1コマあたりのピクセル数）があり、0以外にすると背景が繰り返し並んで流れます。

重ね順は「背景 → 演出効果（キャラの後ろ）→ アイテム → キャラクター → エフェクト → 演出効果（キャラの前）→ カメラ処理 → カットイン → 画面フラッシュ」です。

**「🤖 ロボットアニメ風の攻撃をまとめて配置する」** で、次の流れを一度に追加できます。

1. 攻撃の種類（突進して斬る／ビームを撃つ）と自機を選びます。攻撃ポーズ・敵機・パイロットの顔・命中エフェクト・命中効果音・台詞は任意です。
2. 自機と敵機の位置X、高さY、開始フレームを入力します。
3. 「＋ ロボットアニメ風の攻撃を追加」を押します。

追加される内容：カットイン → 構え（カメラが寄る）→ 突進（集中線・スピード線）またはビーム → 命中（フラッシュ・ヒットストップ・画面揺れ）→ 帰還。12fpsで42コマ（3.5秒）で、他のFPSでは同じ秒数になるようコマ数を合わせます。追加後は各クリップを個別に調整できます。

カットインの文字は、Windowsでは MS ゴシック → BIZ UDゴシック → メイリオ → 游ゴシック の順に、最初に見つかったフォントで描きます。別のフォント（ドット絵用フォントなど）を使う場合は、`.ttf`／`.otf`／`.ttc` ファイルを `pixel_workbench/fonts/` に置くか、環境変数 `PIXEL_WORKBENCH_FONT` にフォントファイルのパスを設定します。

ボイスドラマの音声を使う場合は、同じ画面の **「ボイスドラマの音声をタイムラインに取り込む」** で作品とシーンを選びます。音声はコピーされます。元の音声を編集しても自動同期されないため、反映したい場合は新しいシーケンスへ取り込み直してください。

| 書き出し形式 | 用途・特徴 |
|---|---|
| **GIF** | 無音のアニメーション。透明背景に対応 |
| **MP4** | 効果音付きの映像。背景は不透明 |
| **JSON** | タイミング・配置・素材一覧などの設定 |
| **素材込みZIP** | 設定と使用素材をまとめて保存・受け渡し |

シーケンスの書き出しは最大 **960×540、600フレーム、100クリップ** です。12FPSなら600フレームは50秒です。長い演出は分割してください。これは編集・書き出しの上限で、画像APIが一度に生成できるコマ数とは異なります。

合成・書き出しでは画像生成APIを呼びません。MP4にはFFmpegを使い、シーケンス出力では依存ライブラリに含まれる実行ファイルも利用できます。ゲーム内での再生には、利用するゲームエンジンに合わせた組み込みが必要です。

<a id="aseprite"></a>

## Asepriteと連携する

Aseprite本体をインストールしている場合に使えます。Steam版にも対応しています。

1. 上部の **「Aseprite」** を開きます。
2. **「Aseprite.exeのフルパス」** に実行ファイルの場所を入力し、**「保存・接続確認」** を押します。
3. **「接続テスト用サンプル生成」** で、スプライトが作れることを確認します。
4. **「画像を取り込む」** でPNG／GIF／WebPを選び、**「画像を変換」** を押します。
5. 作成したスプライトを `.aseprite` 形式で保存し、Aseprite側で編集したり、PNG／GIF／スプライトシートとして出力したりできます。

Ollamaを使う **「AIで生成」** は、文章から図形の描画指示を作り、Asepriteで描画する機能です。PixelLabの画像生成とは仕組みが異なります。画像・映像画面で作った素材を渡す場合は、PNGなどに保存してから取り込みます。

通常の画面操作にMCPクライアントの設定は不要です。

<a id="data"></a>

## 保存・バックアップ・更新

台本や編集状態はアプリ内で保存されます。配布・再生用の完成ファイルが必要な場合は、各画面の「書き出し」や「保存」を使ってください。

以下は標準設定での保存場所です。本体フォルダは `app.py` がある場所を指します。

| 場所 | 保存されるもの |
|---|---|
| `workspace/` | ボイスドラマ・ゲーム音声のプロジェクト、共通キャラクター、参照音声、読み方辞書、共通音声素材 |
| `workspace/aseprite_studio/` | Aseprite連携の設定・スプライト |
| `exports/` | ボイスドラマの完成音声 |
| `pixel_workbench/data/` | 画像生成履歴、画像・音声アセット、戦闘シーケンス、画像・映像の出力 |
| ブラウザのダウンロード先 | ダウンロード操作で保存したZIP・Excel・画像など |

**バックアップは、アプリを終了してから `workspace/`、`exports/`、`pixel_workbench/data/` をまとめてコピーします。** 画像・映像のデータは `workspace/` の外にあるため、コピーを忘れないようにしてください。

ZIPで更新する場合は、新しい版を別のフォルダへ展開し、上記のフォルダを同じ位置へコピーしてから起動します。コピー元は、作品を開けることを確認するまで残しておきます。

### APIキーの保存

画像APIの接続画面で **「このPCに暗号化して保存」** を選ぶと、Windowsユーザーごとに暗号化保存され、次回起動時に読み込まれます。保存しない場合は、起動中だけ接続できます。

キーの保存先は `%LOCALAPPDATA%\VoiceDramaStudio\PixelWorkbench\credentials.dpapi` です。作品データとは別の場所にあります。別のPC・Windowsユーザーへ移すときはAPIキーを登録し直してください。Windows以外では、この暗号化保存は利用できません。

## 困ったとき

| 状況 | 確認すること |
|---|---|
| 起動用ウィンドウにPythonのエラーが出る | Python 3.10以降が入っているか、ZIPをすべて展開したかを確認します。初回ライブラリ導入にはネット接続が必要です |
| ブラウザが開かない | 起動用ウィンドウを開いたまま `http://127.0.0.1:8765` を入力します |
| Irodori-TTSのフォルダ・Pythonが見つからない | `infer.py` のあるフォルダを指定したか、`uv sync --extra cu128` で実行環境を作ったかを確認します |
| 音声生成でGPUメモリ不足になる | 小さいモデルや量子化モデルを選び、GPUを使う他のアプリを終了します |
| 名前の読みが違う | 読み方辞書に登録し、対象の台詞を再生成します |
| 修正したのに古い声が再生される | 「要再生成」の表示と、採用中のテイクを確認します |
| MP3を書き出せない・音声を読み込めない | FFmpegを導入し、起動用ウィンドウを開き直します |
| 「別の操作でデータが更新されました」と出る | 同じ作品を複数タブで編集していないか確認し、再読み込みします。まとめて生成している間の編集は控えてください |
| 画像の説明を変えてもサンプルしか出ない | デモモードがオンか確認します。実生成にはAPI接続と費用の確認が必要です |
| 画像生成が失敗した・結果が不明になった | 履歴のエラーとサービス側の結果・利用状況を確認します。すぐに再送すると同じ生成を重ねて依頼する場合があります |
| GIFに音が入らない | GIFは無音です。効果音を含める場合はMP4を選びます |
| Asepriteに接続できない | Aseprite本体をインストールし、`Aseprite.exe` まで含むパスを指定します |

WAVファイルをフォルダ単位でMP3に変換したい場合は、本体の **`batch_wav_to_mp3.bat`** を使えます。FFmpegが必要です。

## 利用する素材・モデルについて

このツールには、音声合成モデル、Aseprite本体、制作に使う参照音声などは含まれません。モデル・APIサービス・音楽・画像・音声の利用条件を確認してください。実在の人の声を参照音声に使う場合は、本人の許可を得てください。
