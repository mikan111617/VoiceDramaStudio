# VoiceDrama Studio — 台本から音声ドラマへ

台本を書くと、登場人物ごとの声で台詞を読み上げ、BGM・効果音と重ねて**ボイスドラマを1本の音声にできる**、パソコンの中だけで動く制作ツールです。TyranoScript（`.ks`）のゲームに**キャラクターボイスを付ける**こともできます。

- 台本は画面で直接書くか、Excelでまとめて作って取り込めます。
- 台詞の読み上げには音声合成AI「**Irodori-TTS**」（または「Qwen3-TTS」）を使います。参照音声（お手本の声）や声の説明から、キャラクターの声を作れます。
- できた台詞音声・BGM・効果音・環境音を、複数のトラックに並べて調整し、WAV／MP3で書き出せます。
- キャラクターの声や読み方の辞書は、すべての作品とゲームで共通に使えます。

> 音声やプロジェクトのデータは、すべてこのパソコンの中（`workspace` フォルダ）に保存されます。インターネットを使うのは、ツールやAIモデルを最初にダウンロードするときだけです。

## 2. 導入手順

初めての人は、上から順番に進めてください。

### 2-1. Python を入れる

1. [python.org](https://www.python.org/downloads/) から Python 3.10 以降のインストーラをダウンロードします。
2. インストール画面の最初で **「Add python.exe to PATH」にチェック**を入れてから「Install Now」を押します。

### 2-2. VoiceDrama Studio を置いて起動する

1. 配布されたZIPを**「すべて展開」**します。日本語や空白の少ない場所（例：`C:\VoiceDramaStudio`）に置くのがおすすめです。
2. 展開したフォルダの **`start_windows.bat`** をダブルクリックします。
   - 初回は必要なライブラリを自動で入れるので、数分かかります。
3. ブラウザで `http://127.0.0.1:8765` が開きます。開かないときは、ブラウザにこのアドレスを入力してください。
4. 黒いウィンドウ（サーバー）は、**使っている間は閉じないでください**。閉じるとアプリが終了します。

> ZIPを開いた画面から直接 `start_windows.bat` を実行すると動きません。必ず「すべて展開」してから実行してください。

### 2-3. Irodori-TTS を入れる（音声合成AI）

このツールにはAIモデルは入っていません。Irodori-TTS を別に用意して、その場所をツールに教えます。

1. **Git** を [git-scm.com](https://git-scm.com/) から入れます。
2. **uv**（Pythonの環境管理ツール）を入れます。PowerShell を開いて次を実行します。

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

3. Irodori-TTS を置きたい場所（例：`C:\`）で、次を順に実行します。

   ```powershell
   cd C:\
   git clone https://github.com/Aratako/Irodori-TTS.git
   cd Irodori-TTS
   uv sync --extra cu128
   ```

   `C:\Irodori-TTS` の中に `infer.py` と `.venv` フォルダができれば成功です。

4. （確認）音声が1つ作れるか試します。初回はAIモデル（数GB）をダウンロードするので時間がかかります。

   ```powershell
   uv run --no-sync python infer.py --hf-checkpoint Aratako/Irodori-TTS-v4.1-Small --text "こんにちは、音声合成のテストです。" --no-ref --output-wav outputs/sample.wav
   ```

   `outputs\sample.wav` ができて再生できれば準備完了です。

### 2-4. FFmpeg を入れる（推奨）

MP3で書き出す・MP3やM4Aを読み込むときに必要です。PowerShell で次を実行するのがかんたんです。

```powershell
winget install --id Gyan.FFmpeg
```

入れたあと、**パソコンを再起動するか、`start_windows.bat` を開き直して**ください。WAVだけを使う場合は、FFmpegがなくても使えます。

### 2-5. アプリでTTSの場所を設定する

1. VoiceDrama Studio の画面右上の **「⚙ TTS環境の設定」** を押します。
2. **Irodori-TTSのフォルダ** に、2-3で用意したフォルダ（例：`C:\Irodori-TTS`）を入力します。
3. **Irodori用Python実行ファイル** は、通常は**空欄のまま**で大丈夫です（フォルダ内の `.venv\Scripts\python.exe` を使います）。
4. 「設定を保存」を押します。この設定はすべての作品とゲーム音声で共通です。

### 2-6. （任意）Qwen3-TTS を使う

Qwen3-TTS は**別のPython仮想環境**で動かします。例：

```bat
py -3 -m venv .venv-qwen3tts
.venv-qwen3tts\Scripts\python.exe -m pip install --upgrade pip
.venv-qwen3tts\Scripts\python.exe -m pip install qwen-tts soundfile
```

GPU用のPyTorchなどはお使いの環境に合わせて公式の手順で入れてください。入れたら「⚙ TTS環境の設定」の **Qwen3-TTS用Python実行ファイル** にその `python.exe` を指定します。

- **Base** モデル：参照音声が必要です。
- **VoiceDesign** モデル：参照音声なしで「声の説明」から声を作れます。

### 2-7. （任意）Ollama で演技指示の案を出す

[Ollama](https://ollama.com/) を入れてモデルをダウンロードし、起動しておくと、台詞の「✦ 演技指示をAIで提案」などが使えます。出てきた案は必ず確認して直してください。

### 2-8. 2回目からの起動・終了

- 起動：`start_windows.bat` をダブルクリック。
- 終了：ブラウザを閉じてから、黒いウィンドウを閉じます。**音声生成の途中では閉じないでください。**

## 4. はじめてのボイスドラマ（基本の流れ）

1. **作品を作る**：上部の作品名を押し、「新規プロジェクト」にタイトルを入れて「この名前で新規作成」。
2. **台本を書く**：「01 台本・台詞」で「＋ セリフを追加」。話者（キャラクター名）と台詞、必要なら演技指示（例：「声をひそめて、警戒しながら」）を入力します。
   - たくさんの台詞をまとめて作るときは、「↓ 一括取り込み用Excelひな形」をダウンロードしてExcelで書き、「↑ Excelの台本を取り込む」で読み込みます（[5-2](#5-2-excelで台本をまとめて作る)）。
3. **シーンを分ける**：左の「＋ シーンを追加」で場面ごとに分けられます。
4. **キャラクターの声を用意する**：「02 キャスト・声」で「＋ 共通キャラクターを追加」し、台本の話者と同じ名前にします。
   - 声のお手本（参照音声）があれば「＋ 参照音声ファイルを登録」。
   - なければ「声の説明」を書いて「✦ Voice Designで声を作成」。気に入るまで作り直せます。
5. **音声を作る**：「01 台本・台詞」に戻り、
   - 表示中のシーンだけなら「✦ このシーンの未生成を生成」
   - 複数のシーンをまとめてなら「✦ 複数シーンをまとめて生成」
   - 特定のキャラクターの台詞だけなら「✦ キャラクターを選んで生成」
   - 1つだけなら、台詞を選んで右下の「✦ この台詞を生成」
6. **聞いて直す**：台詞の「▶ 試聴」で確認。気に入らなければ演技指示を変えて「✦ この台詞を生成」で作り直します。以前の音声（テイク）は残り、右下の「使うテイク」で選び直せます。
7. **BGM・効果音を入れる**：「03 音声ライブラリ」で音声ファイルを追加し、「＋ BGMトラックへ配置」などで並べます。マルチトラックへドラッグしても配置できます。
8. **書き出す**：右上の「↧ 完成音声（WAV/MP3）を書き出す」。シーンごとに作った場合も、「複数のシーンをつなげて1本の完成音声にする」で好きな順番に並べて1つのファイルにできます。アプリのフォルダの `exports` に保存されます。

## 5. ボイスドラマの機能

### 5-1. 台本・台詞（01）

| ボタン | すること |
|---|---|
| ＋ セリフを追加 | シーンの最後に台詞を1つ追加 |
| ✦ このシーンの未生成を生成 | 表示中のシーンの「未生成」「要再生成」の台詞をまとめて音声にする |
| ✦ 複数シーンをまとめて生成 | シーンを選んで（全シーンも可）まとめて音声にする。[5-4](#5-4-音声を作るtts生成) |
| ✦ キャラクターを選んで生成 | 選んだキャラクター（話者）の台詞だけを、全シーンからまとめて音声にする。[5-4](#5-4-音声を作るtts生成) |
| ↑ Excelの台本を取り込む | Excelで書いた台本を読み込む。[5-2](#5-2-excelで台本をまとめて作る) |
| ↓ 一括取り込み用Excelひな形 | 台本をまとめて書くための空のExcelファイルをダウンロード |
| ↓ 手持ちの音声ファイルを台詞に割り当て | 録音済み・作成済みの音声ファイルを台詞に順番に割り当てる。[5-5](#5-5-手持ちの音声ファイルを使う) |
| ↓ このシーンの台詞音声をZIPで保存 | 表示中のシーンの各台詞の、選択中の音声をZIPでまとめてダウンロード |
| 🗑 台本の台詞をすべて削除 | 間違えて取り込んだときなどに台本を空にする（音声ファイル・キャストは消えません。直前の状態はバックアップされます） |

台詞ごとの操作：

| 操作 | すること |
|---|---|
| 話者・台詞・演技指示 | 直接書き換えられます。台詞や演技指示を変えると、その台詞は「要再生成」になります |
| 生成音声のファイル名（任意） | ダウンロードするときのファイル名（例：`mahoru_001.wav`）。空欄なら自動で名前が付きます |
| 次の台詞まで（秒） | この台詞のあとの「間」 |
| ▶ 試聴 | この台詞の音声だけを再生 |
| ↪ タイムラインで位置を表示 | マルチトラック上のこの台詞の位置へ移動（再生はしない） |
| ▶ ここから再生 | この台詞の位置から、BGMなども含めて再生 |
| ＋ この下にセリフを追加 | すぐ下に台詞を追加 |
| テイクN件・生成 → | 右下に、この台詞の生成・テイク選択の画面を開く |
| ↑ ↓ × | 台詞の並べ替え・削除 |

台詞の状態の表示：**音声あり**（できている）／**未生成**（まだ音声がない）／**要再生成**（台詞・演技指示・声の設定・読み方が変わったので作り直すとよい）。

### 5-2. Excelで台本をまとめて作る

1. 「↓ 一括取り込み用Excelひな形」で `voice_drama_template.xlsx` をダウンロードします。
2. **A〜G列の2行目から**台詞を書きます（右側のI・J列は記入ガイドで、取り込まれません）。

   | 台詞ID | シーン | 話者 | 台詞 | キャプション | 間(秒) | 音声ファイル名 |
   |--|--|--|--|--|--|--|
   | （空でOK） | 第一幕 | 真歩流 | サブレがない！ | 周囲を見回しながら驚いて | 0.6 | （任意） |
   | （空でOK） | 第一幕 | 愛理 | 知らないわよ。 | 平静を装う | 0.8 | |

   - **キャプション**は演技指示です。**間(秒)** は次の台詞までの空白です。
3. 「↑ Excelの台本を取り込む」で読み込みます。取り込み方を選べます。
   - **追加・更新**（ふつうはこちら）：Excelにない台詞は残したまま、追加・変更だけを反映します。
   - **シナリオをすべて置き換える**：Excelの内容に入れ替えます（音声ファイルやキャストは消えません。直前の状態はバックアップされます）。
4. あとで台本を直すときは、**「↓ 台本をExcelで書き出す」で台詞ID付きのExcelを保存し、それを直して取り込む**と、どの台詞を直したかが正しく伝わります。

### 5-3. キャスト・声（02）

キャラクターの声は「**共通キャラクター**」として登録します。一度登録すれば、すべての作品とゲーム音声で使えます（[7章](#7-共通キャラクターのしくみ)）。

| ボタン・項目 | すること |
|---|---|
| ＋ 共通キャラクターを追加 | 新しいキャラクターを作る |
| ⇩ 他の作品・ゲームからキャラクターを取り込む | ほかの作品やゲームのキャスト（声の設定と参照音声）を、作品を開かずにコピーする。名前が違うキャラクターへの上書き（例：「警察」→「警察官」）は、取り込み画面の各行の「取り込み先」で選びます |
| 名前・別名 | 台本の話者がこの名前か別名と同じなら、このキャラクターの声で読みます（例：別名に `mahoru` を入れると、話者 `mahoru` でも使われる） |
| TTSエンジン・音声モデル | Irodori-TTS か Qwen3-TTS、使うモデル |
| 生成方式 | **参照音声**（お手本の声に似せる）／**Voice Design**（声の説明から作る） |
| 声の説明 | 声の特徴（例：「20代の女性。明るく澄んだ声」）。台詞に演技指示がないときにも使われます |
| ＋ 参照音声ファイルを登録 | お手本の声（WAV/MP3など）を登録。短いきれいな音声を合計30秒ほど用意すると似やすくなります |
| ✦ Voice Designで声を作成 | 声の説明から声を作り、参照音声にする。画面を閉じずに「✦ 再生成」で作り直し、「この声を使う」で選べます |
| 保存済みの参照音声から追加 | 外した音声や、上書きで置き換わった音声を付け直す |
| キャラクター設定を保存 | 変更を保存（すべての作品に反映され、声が変わる台詞は「要再生成」になります） |

画面下の **「この作品の話者と声」** では、台本の話者ごとに、どのキャラクターの声を使うかを選べます（「自動」は名前・別名が一致するキャラクター）。各話者の「✦ この話者の台詞を生成」で、その話者の台詞だけをまとめて生成できます。共通キャラクターのカードの「✦ この作品のこのキャラクターの台詞を生成」は、この作品でそのキャラクターの声を使う話者（別名や割り当てを含む）の台詞をまとめて生成します。

その下の **「この作品だけのキャスト」** は、共通キャラクターができる前に作品ごとに作っていた声の設定です。「⇧ このキャストを共通キャラクターにする」で共通キャラクターに移せます。カード上部の「VOICE IN USE」には、**実際に生成に使う声（共通キャラクターの参照音声）**が表示されます。

### 5-4. 音声を作る（TTS生成）

- **1つだけ**：台詞を選ぶ → 右下の「✦ この台詞を生成」。
- **表示中のシーンの未生成だけ**：「✦ このシーンの未生成を生成」。
- **複数のシーン・全シーン**：「✦ 複数シーンをまとめて生成」→ シーンを選ぶ（「すべて選択」「未生成があるシーン」も使えます）→ 生成する範囲を選ぶ
  - 「未生成・要再生成の台詞だけ」（ふつうはこちら）
  - 「選んだ台詞をすべて」（できている台詞も作り直します。以前のテイクは残ります）
- **特定のキャラクターだけ**：「✦ キャラクターを選んで生成」→ キャラクター（話者）にチェック → 生成する範囲を選ぶ。最初は全シーンが選ばれているので、そのキャラクターの台詞を作品全体から生成します。シーンを絞ることもできます。キャスト画面の「✦ この話者の台詞を生成」や、共通キャラクターのカードの「✦ この作品のこのキャラクターの台詞を生成」からも、そのキャラクターが選ばれた状態で開けます。
- 確認画面では、シーンとキャラクターを両方選べます（例：「第2幕の真歩流だけ」）。各キャラクターに、選んだシーンでの台詞数と未生成の件数が表示されます。
- 開始前に、使うモデルと件数の確認画面が出ます。
- 大量の台詞は**40件ずつ順番に**作り、できた分からすぐ台本とマルチトラックに反映します。途中で失敗しても残りは続け、終わったあとに失敗した件数と理由を表示します。
- 「■ 生成を停止」で、処理中の40件が終わったところで止まります。
- 生成中にページを読み込み直しても、続きの進み具合を表示します。
- 1回に最大10,000台詞まで。**生成中に台本を編集すると保存が競合しやすいので、長い生成の間は編集を控えてください。**

右下の「使うテイク」で、作った音声の中からどれを使うか選べます。「↓ このテイクを音声ファイルで保存」で1つずつ保存、「🗑 選択テイクを削除」でゴミ箱へ移せます。

**読み方を直したいとき**は「04 読み方」の辞書に登録します（[5-8](#5-8-読み方辞書04)）。台詞を選ぶと右下に「辞書適用後の読み上げ」が表示されます。

### 5-5. 手持ちの音声ファイルを使う

録音した声や、ほかのツールで作った音声も使えます。

1. 「↓ 手持ちの音声ファイルを台詞に割り当て」を押すか、点線の枠に音声ファイルをドラッグ＆ドロップします（複数可）。
2. 割り当てるシーンと開始台詞を選びます。ファイル名の順（`voice_1`, `voice_2`, `voice_10`…）に台詞へ割り当てます。1件ずつ割り当て先を変えることもできます。
3. 「取り込む」。既存の音声は消えず、新しいテイクとして追加されます。

### 5-6. 音声ライブラリ（03）

BGM・効果音・環境音・台詞音声などの素材をまとめて管理します。

| ボタン | すること |
|---|---|
| ↓ 音声ファイルをまとめて取り込む ／ ＋ 音声ファイルを追加 | 素材を追加（表示中のタブの種類で登録されます） |
| セリフ／BGM／効果音／環境音／その他 | 種類ごとに表示を切り替え。検索もできます |
| ▶ 試聴 | 素材を再生 |
| 選択中の台詞の音声にする | 台本で選んでいる台詞のテイクとして使う |
| ＋ 台詞／BGM／効果音／環境音トラックへ配置 | 表示中のシーンのマルチトラックの再生位置に置く（マルチトラックへドラッグしても置けます） |
| ⇄ 共通ライブラリへ登録 ／ この作品の素材をすべて共通ライブラリへ登録 | ほかの作品でも使えるようにする（別の作品では「共通ライブラリ」表示から「＋ この作品へ取り込む」） |
| 🗑 ゴミ箱へ移動 ／ 🗑 選択したN件をゴミ箱へ | 間違えて入れた素材をゴミ箱へ。「🗑 ゴミ箱を確認・復元」で戻せます |

### 5-7. マルチトラック（右上）

- **▶ 再生／■ 一時停止／⏮ 先頭へ**。Spaceキーでも再生・停止できます。
- **ZOOM**：「−」「＋」とスライダーで時間の幅を変更。「シーン全体を表示」でシーン全体を横幅に収めます。
- **クリップの操作**：ドラッグで移動、右端のドラッグで長さを変更。Ctrl（Macは⌘）＋クリックで複数選択、Shift＋クリックで範囲選択。「全クリップを選択」「このトラックを全選択」「このクリップ以降を全選択」「クリップの選択を解除」も使えます。トラック名の「ここから下を全選択」は、そのトラックと下のトラックをまとめて選びます。
- クリップを選ぶと、右下で**音量・フェード・ループ・トリミング・開始位置**を調整できます。
- **↔ 台詞クリップを台本順に並べる**：台詞の音声を、台本の順番と「間」に合わせて並べ直します（手で動かして固定したクリップは動きません）。
- **クリップに波形を表示**：音の大きさが波形で見えるので、ノイズや余計な言葉がどこにあるか目で探せます。細かく見たいときはZOOMの「＋」で拡大します。

#### クリップを分割して、ノイズや台本にない言葉を消す

生成した音声にノイズが入ったり、台本にない言葉をしゃべったりしたときは、その部分だけを切り取れます。

1. 消したい部分のクリップをクリックして選びます。
2. 時間の目盛り（TIME）をクリックするか、再生して止めるかで、**縦の線（再生位置）を消したい部分の始まり**に合わせます。
3. **「✂ 選択クリップを再生位置で分割」**（またはキーボードの **S**）を押すと、クリップが2つに分かれます。
4. 縦の線を**消したい部分の終わり**に合わせ、もう一度「✂ 分割」します。
5. 間にできた短いクリップをクリックし、右下の**「🗑 削除して後ろを詰める」**を押します。後ろの部分と次の台詞が前に詰まり、つながった音声になります。

| ボタン（クリップを選ぶと右下に表示） | すること |
|---|---|
| ✂ 再生位置でこのクリップを分割 | 縦の線の位置でクリップを2つに分けます（ループ再生のクリップは、ループを外してから分割します） |
| 🗑 削除して後ろを詰める | クリップを消して、同じ台詞の後ろの部分と次の台詞を前へ詰めます |
| 🗑 削除（空いた時間はそのまま） | クリップを消し、その部分は無音のまま残します（ノイズを消して間は保ちたいとき） |
| ↺ この台詞の音声を元の長さに戻す | 分割・カットをやめて、選んでいるテイクを最初から最後まで使います |

- 分割した後ろの部分（タイムラインに「✂」が付きます）は、元の台詞と一緒に動きます。台詞の順番や「間」を変えても、まとめて並び直します。
- 分割したクリップも、ドラッグで位置を変えたり、音量・フェードを個別に変えたりできます。間違えたときは「↶ 戻す」（Ctrl＋Z）で元に戻せます。
- 分割・カットの結果は、マルチトラックの再生と**完成音声の書き出し**に反映されます。「このシーンの台詞音声をZIPで保存」や「↓ このテイクを音声ファイルで保存」は、生成したテイクをそのまま保存します（カット前の音声です）。
- 台詞を**生成し直す**か**テイクを切り替える**と、新しい音声には前のカット位置が合わないため、分割は解除されて音声全体が1つのクリップに戻ります。
- 「＋ トラックを追加」でトラックを増やせます。エクスプローラーからBGM・効果音・環境音のトラックへ音声ファイルを直接ドロップすることもできます。

### 5-8. 読み方辞書（04）

Irodori-TTS は漢字の読みを間違えることがあります。語と読みを登録すると、**音声を作るときだけ**読みに置き換えます（台本の文字は変わりません）。辞書はボイスドラマとゲーム音声で共通です。

- 「＋ 単語を追加」で語（例：`舞黒館`）と読み（例：`まいくろかん`）を登録します。
- 1つの語に複数の読み方（読みパターン）を登録し、台詞ごとに選び分けられます（台詞を選ぶと右下に選択欄が出ます）。
- 「↑ 辞書JSONを取り込む」「↓ 辞書JSONを書き出す」で、ほかのパソコンとやりとりできます。
- カタカナの名前（メアリーなど）は、ひらがなにしない方が自然に読まれることが多いです。

### 5-9. 完成音声の書き出し

右上の「↧ 完成音声（WAV/MP3）を書き出す」を押します。

- **出力範囲**
  - **表示中のシーンだけ**：今開いているシーンを1つのファイルにします。
  - **複数のシーンをつなげて1本の完成音声にする**：つなげるシーンにチェックを入れ、「↑」「↓」で順番を並べ替えます（作品のシーンの並びは変わりません）。「すべて選択」「音声があるシーン」「選択解除」でまとめて選べます。各シーンの長さと、つなげたときの合計の長さ・順番が表示されます。
  - **シーンの間の無音**：シーンの切れ目ごとに、無音の長さ（0〜60秒）を決められます。
    - 「シーンの間の無音をまとめて設定」に秒数を入れて「すべての切れ目に適用」を押すと、全部の切れ目が同じ秒数になります（初期値1秒）。
    - そのあと、各シーンの下の「⏸ 次の「○○」まで無音 □ 秒」で、切れ目ごとに個別に変えられます（例：場面転換は3秒、同じ場所の続きは1秒）。
  - **切り替わりの試聴**：各切れ目の「▶ 切り替わりを試聴」で、「前のシーンの終わり → 無音 → 次のシーンの始まり」を再生します。再生する長さは「切り替わりの試聴：前後それぞれ □ 秒」（1〜30秒、初期値5秒）で決めます。書き出しと同じ方法で音を作るので、聞いたとおりの音で書き出されます。もう一度押すと止まります。
  - 選んだシーン・順番・切れ目ごとの無音・試聴の長さは作品に保存され、次に書き出すときもそのまま使えます。
  - 1回の書き出しは合計2時間までです。
- **出力形式**：WAV（PCM16）／MP3（192kbps、FFmpegが必要）。
- **作品タイトル・制作名義・ジャケット画像**（MP3のみ埋め込み）を指定できます。
- 保存先はアプリのフォルダの **`exports`**（ファイル名は作品タイトル）。同じ名前のファイルがあるときは上書きするか確認します。「📁 保存先フォルダを開く」で開けます。

## 6. ゲーム音声（TyranoScript）

上部の「🎮 ゲーム音声」に切り替えます。ボイスドラマとは別のプロジェクトとして保存され、**元の `.ks` ファイルは書き換えません**。

### 基本の流れ

1. **プロジェクトを作る**：作品名の欄から「＋ 新しいプロジェクト」。
2. **シナリオを取り込む**（「04 ファイルの取り込み」）
   1. 以前に発行したボイスIDの続きから番号を付けたいときは、先に「↥ ボイスID履歴を読み込む」。
   2. 「① KSを読み込む」で `.ks` を読み込みます（何回かに分けて追加できます）。
   3. すべて読み込んだら「② 全KSのボイスIDを一括確定」。台詞ごとに `v00001` のようなボイスIDが付きます。
   - KSの代わりにボイスリストのJSONから作る場合は「＋ ボイスリスト JSON を取り込む」。
3. **キャラクター情報を取り込む**（推奨）：「↥ キャラクターシート（JSON）を取り込む」。登録した人物だけが音声の対象になり、`#TIPS` のようなシステム表示は除かれます。「↥ 作品コンテキスト（JSON）を取り込む」は任意です。
4. **声を決める**（「02 キャスト・声」）：話者ごとに、使う共通キャラクターを選ぶか、「ゲーム音声専用の声設定」にします。
5. **読み方・アクセント**（「03 読み方・アクセント」）：読み方辞書はボイスドラマと共通です。アクセント辞書はゲームのプロジェクトごとです。
6. **演技指示（キャプション）を付ける**（任意）
   - 1件ずつ：台詞を選んで右側で編集し、「この台詞の変更を保存」。
   - まとめて：「↓ 全シナリオのキャプションCSVを書き出す」→ ChatGPTやClaudeにCSVと「⧉ キャプション作成用のAI依頼文をコピー」でコピーした依頼文を渡す → 返ってきたCSVを「↑ 記入済みキャプションCSVを取り込む」。ボイスIDや台詞が変えられていた場合は取り込みを止めます。
7. **音声を作る**（「01 台本・台詞」）：左のシナリオ一覧のチェック、「未生成の台詞を選択」「全台詞を選択」「この話者を選択」などで選んで「✦ 選択した台詞を生成」。40件ずつ作り、途中で止めたり、ページを読み込み直して続きを見たりできます。
   - 1件だけ作り直すときは、台詞を選んで右側の「読み上げテキスト」（元のKSとは別に直せます）を直し、「✦ この台詞を生成」。
8. **書き出す**：右上の「↧ ゲーム用に書き出す（ZIP）」。音声、ボイスID付きのKSのコピー、ボイスIDと音声ファイルの対応表（voice map）などをまとめたZIPができます。

### 設定（⚙ 生成とTTS環境の設定）

音声の保存形式（WAV／MP3）、生成ステップ数、Ollamaのモデル名、TTS環境（ボイスドラマと共通）、画面のパネル配置の初期化をまとめています。

### WAV → MP3 の一括変換ツール

フォルダ内のWAVをまとめてMP3にするときは、アプリのフォルダの **`batch_wav_to_mp3.bat`** をダブルクリックします（FFmpegが必要）。入力フォルダと保存先を選んで「変換開始」。フォルダの階層とファイル名はそのままで、元のWAVは変更しません。

## 7. 共通キャラクターのしくみ

- キャラクターは **`workspace/characters`** にまとめて保存され、ボイスドラマのすべての作品とゲーム音声のすべてのプロジェクトで共通です。
- 台詞の話者が、キャラクターの**名前か別名**と一致すると、そのキャラクターの声で読みます（全角・半角、大文字・小文字の違いは無視します）。ゲーム音声では、キャラクターシートの表示名・別名も照らし合わせます。
- **どの声が使われるか**（上にあるものが優先）
  - ボイスドラマ：「この作品の話者と声」で選んだキャラクター → 名前・別名が一致する共通キャラクター → この作品だけのキャスト
  - ゲーム音声：ゲーム音声専用の声設定 → 話者ごとに選んだ共通キャラクター → 以前のボイスドラマのキャストの割り当て → 名前・別名が一致する共通キャラクター
- キャラクターを直すと、そのキャラクターを使う台詞のうち、**声が変わるものだけ**が「要再生成」になります。音声ファイルは消えません。
- キャラクター名を変えると、元の名前は別名として残ります。

## 8. 困ったとき（よくある質問）

| 困りごと | 対処 |
|---|---|
| 「Irodori-TTSのフォルダを指定してください」と出る | 「⚙ TTS環境の設定」で、`infer.py` が入っている Irodori-TTS のフォルダを指定してください |
| 「irodori用Pythonが見つかりません」と出る | Irodori-TTS のフォルダで `uv sync --extra cu128` を実行して `.venv` を作ってください（[2-3](#2-3-irodori-tts-を入れる音声合成ai)） |
| 生成が失敗する・とても遅い | NVIDIAのGPUとドライバを確認してください。メモリ不足のときは「Irodori v4.1 Small」や「Irodori Large INT8」を選び、ほかの重いアプリを閉じてください。失敗の理由は生成画面に表示されます |
| 声がキャラクターに似ない | 参照音声は雑音・BGM・ほかの人の声が入っていない、きれいなものを使ってください。合計30秒ほどあると似やすくなります。声の説明は参照音声の声と食い違わない内容にします |
| 演技が不安定・変な間が入る | 演技指示は「どんな声で、どう聞こえるか」を短く書くと安定します（例：「若い女性が、驚いて短く声を上げている」）。「間を置く」「途切れがちに」のような指示より、台詞の中に「……」「、」を書く方が確実です |
| 読み方を間違える | 「04 読み方」の辞書に登録してください |
| キャストのカードに「参照音声 0件」と出る | カード上部の「VOICE IN USE」に、実際に使う共通キャラクターの参照音声が表示されます。そこも0件なら、共通キャラクターに参照音声を登録してください |
| 作品を開いたとき「音声ファイルが見つからないテイクを○件外しました」と出る | 音声素材がなくなっているテイク（以前の版で保存できてしまっていたもの）を自動で外しました。外したテイクが選ばれていた台詞は、残っている別のテイクに切り替わるか「未生成」に戻ります。生成し直せば元どおりになります。修復前のデータは作品の `backups` フォルダに保存されています |
| 保存時に「台詞「…」のテイクが指す音声素材がありません」と出る | F5で読み込み直してから、もう一度操作してください |
| 「別の操作でデータが更新されました。再読み込みしてください」と出る | 同じ作品を2つのタブで開いている、または生成中に編集した場合に出ます。F5で読み込み直してください |
| MP3で書き出せない | FFmpegを入れてください（[2-4](#2-4-ffmpeg-を入れる推奨)） |
| `start_windows.bat` で文字化け・エラーが出る | ZIPを「すべて展開」したフォルダから実行してください。Pythonが入っていない場合は[2-1](#2-1-python-を入れる)を確認してください |
| 「8765」番ポートが使えない | 環境変数 `VDS_PORT` に別の番号を指定して起動できます |
| ゲーム音声で「音声ファイルなし」になる | 「未生成の台詞を選択」で、未生成・要再生成・ファイルがない台詞だけを選んで作り直せます |

## 9. データの保存場所・バックアップ・更新

| 場所 | 中身 |
|---|---|
| `workspace/p_.../` | ボイスドラマの作品（台本、テイク、マルチトラック、音声ファイル、バックアップ） |
| `workspace/characters/` | 共通キャラクターと参照音声 |
| `workspace/shared_audio/` | 共通ライブラリのBGM・効果音・環境音 |
| `workspace/game_voice/` | ゲーム音声のプロジェクトと生成音声 |
| `workspace/global_settings.json` | TTS環境の設定と読み方辞書 |
| `exports/` | 書き出した完成音声 |

- **バックアップ**：アプリを閉じてから `workspace` フォルダをまるごとコピーしてください。
- **新しい版への更新**：新しい版を別のフォルダに展開し、古い版の `workspace` フォルダを新しい版の同じ場所へコピーします。古いフォルダはしばらく残しておくと安心です。
- 削除した素材やテイクは各作品の `trash` フォルダへ移り、音声ライブラリの「🗑 ゴミ箱を確認・復元」で戻せます。台本の全削除やExcelでの置き換え、シーンの削除、音声が見つからないテイクの自動修復の前には、作品の `backups` フォルダに自動でバックアップが作られます。

## 11. 開発者向け

```bash
python -m pip install -r requirements.txt
python -m pip install pytest httpx
python -m pytest -q tests
# Node.js がある場合は画面ロジックのテストも実行できます
node --test tests/test_game_ui.js tests/test_timeline_selection.js tests/test_drama_generation_targets.js tests/test_clip_split.js
python app.py   # http://127.0.0.1:8765
```

- 画面（ブラウザ）とTTSは別のプロセスで動きます。TTSは `tts_worker.py` を、⚙ の設定で指定したPython環境で実行します。
- 主なファイル：`app.py`（ボイスドラマのAPI）、`core.py`（作品データ）、`game_voice.py`・`game_voice_api.py`（ゲーム音声）、`characters.py`（共通キャラクター）、`render.py`（ミックス・書き出し）、`static/`（画面）。
- 機能ごとの詳しい仕様と更新履歴は [CHANGELOG.md](CHANGELOG.md) にあります。

## 権利と注意

- このツールには音声モデル・モデルの重み・参照音声は含まれていません。Irodori-TTS・派生モデル・Qwen3-TTS・生成した音声の利用条件は、それぞれのモデルの説明を確認してください。
