# PixelLab + GPT Local Workbench v0.7

**Windows向け・ブラウザ操作のローカル画像制作ツール**です。v0.7では、v0.6のカテゴリー別アセット管理と戦闘シーケンス編集を拡張し、**再生プレビュー／効果音同期／クリップの移動・尺調整／GIF・音声付きMP4・JSON・素材込みZIP出力**に対応しました。既存のVoiceDramaStudio／シナリオ管理ツールには手を加えていません。



## v0.7 新機能：戦闘シーケンスの再生と書き出し

1. 「アセット管理」から、キャラクターのPNG/GIF、魔法エフェクト、効果音（WAV/MP3/OGG/M4A）を読み込みます。**スプライトシートPNGは列・行数を入力して分割**できます（最大64コマ）。
2. 「戦闘シーケンス」で新規作成し、FPS（初期値12）、キャンバスサイズ、名前を決めます。
3. アセットを選んでキャラクター・アイテム・背景・エフェクト・効果音レーンに追加します。開始フレーム、長さ、座標（X/Y）、音量を指定できます。画像と音声を異なるレーンに誤登録しないようチェックします。
4. **再生**で画像と効果音を同期プレビュー。スライダーでコマ送りできます。タイムラインのクリップをクリックすると編集欄に内容を読み込みます。クリップを左右にドラッグして開始位置を移動、右端をドラッグして長さを調整し、変更を保存できます。
5. **書き出し**はJSON（設定・素材一覧）、素材込みZIP（`project.json` と必要なアセット）、GIF（無音／背景透過）、MP4（映像と効果音／背景不透明）に対応します。

### データ・座標・制限

- ステージはRGBA合成。**キャラクター・アイテム・エフェクトのX=0,Y=0は画面中央**、背景はステージ全面に拡大して左上を基準に配置します。各アセットは元画像のピクセルサイズで描画されます。
- 音声は指定フレームから再生し、クリップの長さを超えた部分はカットされます。ブラウザの音声形式対応状況によりプレビューが再生できない場合がありますが、MP4ではFFmpegで合成します。
- GIFには音声を格納できません。音が必要ならMP4を選んでください。MP4はH.264/AACで、透明背景を持てないため濃い背景色で合成します。
- **画面は最大960×540、書き出しは最大600フレーム・100クリップ**です。長いシーケンスは分割してください。大きな画像を多数重ねると処理が遅くなることがあります。
- **MP4書き出しにはFFmpegが必要**です。v0.7の`requirements.txt`にはWindows用のバイナリも導入される`imageio-ffmpeg`を追加しました。初回の`start_windows.bat`実行時にインストールされます。
- 映像・GIF・音声合成はローカルのPC内だけで処理され、**PixelLabやOpenAIの追加API呼び出しは発生しません**。
- v0.7で追加した書き出し済みファイルは`data/exports/`へ保存されます。素材は`data/assets/<カテゴリー>/<ID>/`、元の生成履歴は`data/outputs/<ジョブID>/`に保存されます。

### v0.6から更新する場合

1. 両方の版を終了してください。
2. **v0.6フォルダの`data`をバックアップ**してから、v0.7の`PixelLab_GPT_Workbench`直下へコピーしてください。v0.7の空の`data`を上書きできます。
3. `start_windows.bat`から新しい版を起動してください。アセットとシーケンスのJSON形式は継続利用できます。APIキーは元々ディスク保存されないため、必要なら再登録してください。

## v0.5 新機能：魔法・攻撃エフェクト（PixelLab VFX）

**画面上の「⚡ 魔法・エフェクト」タブ**から使います。キャラクターなしで落雷・爆発・炎・魔法陣・斬撃などのアニメーションを作成し、ブラウザ内で結果を見ながら GIF / スプライトシートPNG / フレーム配置JSON（提供された場合）/ ゲーム用ZIP（提供された場合）を保存できます。

1. 利用サービスは **PixelLab API** を選びます。
2. 「⚡ 魔法・エフェクト」を選択し、モデルは **Lite**（生成枠少なめ）または **Pro**（高品質・生成枠多め）を選びます。
3. 「⚡ 落雷魔法」などの例を押すか、自由な指示を入力します。人物なしなら参照画像は不要です。
4. 先に「デモモード」で無料の落雷サンプルを確認します。デモは実際のAI生成ではありません。
5. 実際に生成するときはPixelLabのAPIキーを設定し、デモをオフにして確認ダイアログを読んで生成します。
6. 完了後に右側のプレビューを確認し、GIF・PNG・JSONなどがあれば保存します。履歴に残るので別ウィンドウで作業できます。

### 課金と制限

- PixelLab VFXの `POST /v2/vfx` を使用します。**Liteはキャラクターなしなら概ね1生成枠、Proは概ね6生成枠**から。参照スプライトを付けるとサイズによって増える場合があります。実際の消費は提出後の公式見積・完成時の使用量によります。長時間処理により見積枠の約2倍に達する場合があります。
- **生成枠と米ドル請求額は別**です。生成枠の消費を、架空のUSD金額に換算して表示しません。ローカルで予約するUSD予算は請求の厳密な上限ではありません。公式残高を併せて確認してください。
- キャラクターを重ねたい場合の参照PNGは、1フレーム最大512×512px以下です。現行ツールでのVFX入力は静止画PNG/JPEG/WebP（正規化してPNGとして送信）です。GIFなど複数フレームの参照スプライトはこの版では非対応です。
- 出力フレーム数やFPSはVFXアーティスト側が決めます（カスタム数値指定のAPIパラメータとはしていません）。必要な長さ・スピードは指示文に記載してください。
- 安全のため、**PixelLabドメインからのHTTPSファイルのみ自動ダウンロード**します。PixelLabが別ドメインへの出力に変更した場合は、結果がMy effectsにあるのにローカル保存に失敗する場合があります。APIジョブを再送して二重課金しないでください。
- 実APIの課金生成は未実施であり、実行時のAPI応答が変わっていれば調整が必要です。

### GBA時代の戦闘アニメーションについて

『ファイアーエムブレム』GBA版のような戦闘演出を作る場合、「アニメ生成」モードで剣士の**待機・構え・踏み込み・斬撃・復帰**などを区切って作り、VFXモードで斬撃・落雷・火花などを別素材として制作するのが現実的です。継ぎ目・タイミング・座標の統一は追加の編集が必要です。**この版では簡易的な戦闘シーケンス編集とタイムライン管理を搭載**しました。v0.7ではGIF/MP4の最終合成も追加しています。

## 0. v0.4 で追加：画面内でつながる操作

- **PixelLab API / GPT画像API**：サービスを選択 → 元画像・指示 → 「生成する」 → 右側でプレビュー・比較・保存まで一画面で完結します（API利用料金がかかる場合があります）。
- **Ollama（任意）**：同じ画面で元画像の分析、プロンプト改善、生成画像との比較ができます。起動していなくても画像生成は使えます。
- **ChatGPT Plus**：このツール内にChatGPTの生成画面を埋め込む公式手段はありません。指示をコピーして公式ChatGPTで画像を生成し、画像自体をコピーしたあと本ツールに戻って **Ctrl+V**。保存せず自動的に履歴へ追加し、右側の比較画面に表示します。ドラッグ＆ドロップや画像ファイル選択も可能です。クリップボード読み取りボタンはブラウザの権限設定によっては使用できません。
- **やり直し**：「この画像を元に再生成」で生成画像を参照画像にセット。「設定を再利用」でプロンプト、選択モデル、元画像などを復元します。外部APIへの自動再送はしません。
- **参照画像の貼り付け**：API方式の「画像から変換」「アニメ生成」では、参照画像を Ctrl+V やドロップで指定できます。
- **画面の広さ**：APIキー・料金設定は初期状態で折りたたまれています。「接続・料金を表示」で開けます。別ウィンドウで複数ツールを同時表示することもできます。

**重要**：ChatGPT Plusの画像生成をこのローカルツール内から自動的に呼び出したり、Plusの利用枠をAPIに流用したりすることはできません。完全自動の同一画面操作には、別料金のOpenAI画像APIを選択してください。ChatGPTのログインCookieや認証トークンを抜き取るような自動操作は実装していません。

## 1. 始め方

1. ZIPをすべて展開します。`start_windows.bat` だけを別の場所に移動しないでください。
2. Windowsに **Python 3.10以上** が必要です。未導入なら https://www.python.org/downloads/ からインストールしてください。
3. `start_windows.bat` をダブルクリックします。初回はインターネット経由でPythonライブラリを導入します。
4. 自動でブラウザが開きます。開かなければ黒い画面に表示された `http://127.0.0.1:8765` などのURLを直接開きます。
5. まず **「デモモード」をオン** にして動作を確認してください。デモはAPI送信・課金をしません。
6. 本物の画像をAPI経由で生成するときは、PixelLabまたはOpenAIのAPIキーを「API接続と利用状況」に登録し、デモモードをオフにします。送信前には確認画面が出ます。ChatGPT PlusモードはAPIキー不要ですが、画像生成そのものは公式ChatGPT画面で行います。
7. 終了は黒いウィンドウで `Ctrl+C`。起動中はウィンドウを閉じないでください。

**重要：PixelLabのSecretが過去のスクリーンショットに写っていた場合、そのキーをPixelLabのアカウント画面で再発行してから登録してください。**

## 2. サービスと生成モードの組み合わせ

| サービス | 新規生成 | 画像から変換 | アニメーション | VFX | 設定 |
|---|---|---|---|---|
| PixelLab Standard | Pixen `/create-image-pixen` | `/image-to-pixelart` | `/animate-with-text-v3` | `/vfx` Lite | 画像サイズ・標準変換の忠実度 |
| PixelLab Pro | `/generate-image-v2` | `/image-to-pixelart-pro` | `/animate-with-text-v3`（共通） | `/vfx` Pro | 高品質生成・画像変換の任意プロンプト |
| GPT Image 2 | `/v1/images/generations` | `/v1/images/edits` | 未対応 | 未対応 | 品質・画像サイズ・忠実度の文章指定 |
| GPT Image 2.5 Flare / Sunburst | 同上 | 同上 | 未対応 | 未対応 | 画像制作／編集（高品質） |
| ChatGPT Plus（貼り付け） | 公式ChatGPT画面で生成 | 元画像は公式画面に手動添付 | このツールでは未対応 | 未対応 | 生成画像をコピーして本ツールへ Ctrl+V で取り込む |

**PixelLab Standardの忠実度**：
- 「忠実」では公式の `fixer=true` と `init_image_strength=230` を設定します。オリジナルの顔・服・頭身をなるべく維持したい場合の出発点です。
- 「標準」はAPIの初期設定に近い状態です。
- 「アレンジ」は構図を再解釈しやすい設定です。

**PixelLab Proの注意**：`image-to-pixelart-pro` の出力サイズは **API側が自動決定** します。Standardと異なり忠実度スライダー相当の直接パラメータはないため、追加指示欄（例：顔の輪郭・頭身・衣装を変えない）で補足します。

**GPT画像APIの注意**：元画像を編集するときは元画像がOpenAI APIに送信されます。「忠実」プリセットは編集プロンプトを補うだけで、元画像と完全一致する保証はありません。GPTからの画像は高解像度で、PixelLabのようなネイティブの格子ドット絵が必ず得られるわけではありません。新規画像の場合も「pixel art」の説明文を自動で付与します。

## 3. APIキーについて

- PixelLab Secret： https://www.pixellab.ai/account
- OpenAI APIキー： https://platform.openai.com/api-keys
- OpenAIの利用料金： https://developers.openai.com/api/docs/pricing
- PixelLab公式API： https://api.pixellab.ai/v2/docs

**ChatGPT Plusの契約だけではOpenAI APIを無料で利用できません**。OpenAI PlatformでAPIの請求設定と利用制限を確認してください。PixelLabの無料生成枠はOpenAI APIでは使えません。両者は別の残高管理です。

APIキーは**アプリ起動中のメモリ**だけに持ち、履歴ファイルには書き込みません。ローカルPCの `127.0.0.1` のみに公開します。APIキーは環境変数 `PIXELLAB_API_KEY`、`OPENAI_API_KEY` からの読み込みも可能です。環境変数の管理はPC側で行ってください。

## 4. 料金表示と予算ガード

- **PixelLab残高**：PixelLab `/balance` から取得。OpenAI APIの残高をここに混ぜません。
- **事前参考料金**：Pixen等は参考値。GPT Image 2は**画像出力部分のみ**の公式参考額（テキスト・参照画像の入力料金は別）。PixelLab ProとGPT Image 2.5は、条件ごとに変動するため「要確認」と表示。
- **予算予約**：料金が分からない場合、事前に `0.50 USD` などの仮予約枠を指定します。これは**API側の課金上限ではありません**。月間予算ガードも実請求を保証・停止しません。
- **生成後の記録**：PixelLabは`usage`や残高差から判明分を記録。GPT画像APIは応答から確定額を取得できない場合に **「請求額不明」** と表示。ゼロドルと誤認しないようにしています。
- **今月の確認済み額** は全体の請求額ではありません。必ず各サービスの公式ダッシュボードも確認してください。
- APIへ送信した後のタイムアウト等は、二重課金を避けるため自動再送しません。

**初回はデモで操作感を確認し、実際のAPI利用時も低品質／Standardから少量ずつ試す**のがおすすめです。

## 5. 画像比較と保存

画像から変換した場合は、生成後に「元画像」と「生成結果」を横に並べて比較できます。さらに「左側に比較表示する画像」から、**別の履歴（Standard／Pro／GPTの結果）**を選んで二つの生成結果を見比べられます。

- 静止画：PNG
- アニメ：連番PNG・GIF・横一列のスプライトシート
- 参照画像：`reference.png` も生成ジョブ内に保存（**元画像がローカルに残ります**）
- 結果評価：👍良い / 👎悪い（**学習には使いません**）
- 保存先：`data/outputs/<ジョブID>/`
- 設定・履歴：`data/state.json`（APIキーを含みません）

旧版v0.1／v0.2の生成履歴を持ち越すなら、**アプリを両方停止した状態で** 旧版の `data` フォルダをv0.3のフォルダへコピーしてください（既存データがある場合はバックアップを先に）。`data` にはAPIキーは保存されません。

## 6. 制限と確認状況

- API呼び出し・応答解析・履歴保存は**模擬応答による自動テスト**済み。実APIへの有料リクエストは未実施のため、アカウントの権限・最新の仕様・料金・サービス側エラーで調整が必要になる場合があります。
- GPT画像を実ドット絵のピクセルグリッドに自動変換する処理はまだありません。
- GPT画像APIにアニメーション生成はありません（このツールのアニメ機能はPixelLabのみ）。
- Windows起動にはネット接続が必要（初回導入とAPI利用）。画像はクラウドで生成し、UI・保存・履歴管理はローカルで実行します。
- ブラウザウィンドウは複数開けますが、**生成中に黒い起動ウィンドウを閉じるとジョブの状態が不明になる可能性があります**。
- 正確な公式請求額はサービス側の管理画面でご確認ください。

## 8. 新機能：ローカルLLM（Ollama） — 使いたいときだけ

**Ollamaがなくても、従来のPixelLabとGPT画像API、ChatGPTブラウザモードは動作します。**

1. WindowsにOllamaをインストールして起動します。公式サイト：https://ollama.com/download
2. Ollamaで**ローカルモデル**をダウンロードします。画像解析には画像を理解できる **Vision対応モデル** が必要です。画像のないプロンプト改善だけなら通常のテキストモデルでも利用できます。
3. 本ツール内の「ローカルLLMアシスタント」にある「接続確認」を押します。モデルを選びます。
4. 文章を改善したい場合は「プロンプト改善」、元画像の特徴を確認したい場合は「画像の特徴を抽出」を押します。
5. 提案はまず別欄に表示されます。「この文章をプロンプトに反映」を押すまで生成条件は変更されません。気に入らない場合は元の指示へ戻せます。
6. **生成後**、元画像を含む履歴を開き「Ollamaで元画像と生成結果を比較する」を押すと、相違点と次に試す指示文が表示されます。この機能では**2枚の画像を受け付けるVisionモデル**が必要です。モデルによっては利用できません。

Ollamaとの通信は `127.0.0.1:11434` のみです。このアプリはクラウド指定タグ `:cloud` のモデルを選択肢から除外します。外部のPixelLab／OpenAI APIを**Ollamaの補助操作から呼び出すことはありません**。なおOllama自身の設定や外部のモデルについては、利用者側でも確認してください。

**特に重要**：PixelLab Standardの`/image-to-pixelart`は、変換の追加指示文を直接受け取るAPIではありません。Standardでは忠実度パラメータを優先し、ローカルLLMが改善した文章の効果を確認するには **PixelLab Pro / GPT画像API / ChatGPTブラウザ** を選んでください。

## 9. 新機能：ChatGPTブラウザ（API追加料金なし）

1. 「利用するサービス」で「**ChatGPTブラウザ / アプリ（手動）**」を選びます。
2. 新規生成か画像から変換を選び、プロンプトを入力します。元画像がある場合、ツールに読み込ませておくと比較に利用できます。
3. 「**指示をコピーしてChatGPTを開く**」を押します。クリップボードにコピーできない場合、直上のプロンプト欄から手動コピーしてください。
4. ChatGPTで指示文を貼り付けます。元画像がある場合は、**自分でChatGPTに添付**してください。
5. ChatGPTの画像生成機能で生成し、画像をPCへ保存します。
6. このツールの「生成して保存した画像」を指定し、「**画像を履歴へ取り込む・比較する**」をクリックします。元画像やPixelLab結果と比較できます。

このモードはChatGPTの画面を自動操作しません。**ChatGPT Plusの利用枠をAPIとして利用することもできません。** このツールからのOpenAI API課金は発生しませんが、ChatGPTのプラン料金と画像生成利用枠は別に適用されます。自動的な料金取得も行いません。

## 10. 更新・トラブルシューティング

- v0.2から更新する場合、前版を終了後、`data`フォルダをv0.3の`PixelLab_GPT_Workbench`フォルダへコピーすれば生成履歴を移行できます。**元のフォルダは削除せずバックアップ**してください。
- 「Ollama未接続」は画像生成機能のエラーではありません。必要なければ無視できます。
- 「Ollama 400 / images unsupported」の場合はVisionモデルを選択してください。モデルによっては2枚同時の画像比較に非対応です。
- 実APIによるPixelLab ProとGPT画像の生成は開発環境では未課金・未接続で、モックテストのみです。API仕様やプラン権限の違いによって実環境では追加調整が必要になる可能性があります。
- 「ChatGPTブラウザ」モードで生成ボタンが表示されないのは仕様です。ブラウザで生成してから画像を取り込んでください。
